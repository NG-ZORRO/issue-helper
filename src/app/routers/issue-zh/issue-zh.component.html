首先，虽然我们为了中文用户的方便提供了中文的表单，但在填写时请 尽量使用英文 。NG-ZORRO 社区不只有中国人。如果你想让尽可能多的人能够看懂你的 issue，就请尽量用英文。

其次，Ant Design 的 issue 列表只接受 bug 报告或是新功能请求 (feature requests)。这意味着 我们不接受用法问题 。如果你开的 issue不符合规定，它将会被 立刻关闭 。 为什么要这么严格？

对于使用中遇到的问题，请使用以下资源：

  • 仔细阅读 文档
  • 在 StackOverflow (英文) 或是 Github (issues) 搜索和提问
